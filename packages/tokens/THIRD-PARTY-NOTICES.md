## Tailwind CSS

`tailwind/base/color/palette.css` holds the 286 color values of the Tailwind
CSS v4 default theme. The colors themselves are unchanged; only the hue
component of the achromatic steps is written as `0` rather than `none`.

Tailwind CSS is also the framework this package extends.

## digital-go-jp/tailwind-theme-plugin

The typography scale in `tailwind/base/typography/utility.css` follows the
Digital Agency Design System as published through that plugin. The utilities
are written from scratch for Tailwind v4; the font sizes, line heights and
letter spacings come from the plugin's scale.
